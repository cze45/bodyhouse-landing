# BodyHouse Pančevo – landing stranica

Jednostranični sajt za BodyHouse (Miloša Obrenovića 37, 26000 Pančevo).

## Fajlovi

- `index.html` – kompletna stranica u jednom fajlu, radi bez build koraka.

## Objava

Stranica je statična. Može se objaviti na GitHub Pages, Netlify ili Vercel:

1. Commit `index.html` u root repozitorijuma.
2. GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Pre objave

- Dodati fotografije: hero pozadina, tim, galerija i karusel (trenutno sivi placeholderi).
- Upisati imena i uloge članova tima.
- Upisati pravo radno vreme u futeru (trenutno 00:00-00:00).
- Povezati formu "Ostavi nam poruku" sa servisom (Formspree, Netlify Forms ili sl.). Trenutno samo prikazuje potvrdu i ne šalje podatke.
